Project Description:
This is a page for Creek Haven University designed for students to learn about current happenings and help them to stay engaged. They can see all things from upcoming sports to activities to get them out of their dorms. The intended audience is Creek Haven University students and professors. 

This webpage contains and index page that is the Home page. The Home page has information about the school, upcoming events and a link to the event page. 

The event page has all the information about the annual fall festival that students and professors need to come and partake in the event. 

Layout Decisions: 
I used CSS Grid is several areas of the website. 
In the navigation, it is used to create boxes around my links and evenly spread them around. 
I also used it in the upcoming events section to create a box for each event and organize the information in the most organized way. 

I used Flexbox in multiple areas as well.
I used it in the Footer to evenly spread the boxes on the bottom of the page. I also allows them to move when the area of the screen grows or shrinks. 
It was used in the related events in the events page as well to allow the boxes to wrap when the screen becomes small. 

I added JavaScript to allow users to add events that they want to attend into a saved events category. 


Responsive Design:
The first responsive design element that I used was for the Hero page. When the width is greater than or equal to 600px, the background picture's size stays at 1500px. However, when it is less, it's size is cover so it can move with the page. 

The second I used was the event layout in the Main content and sidebar section. When the screen is less than 900px, the Event Details section goes under the About Event section. When the screen is larger than 900px, they go beside one another. 

These were tested by implementing the design and resizing the browser to see how the page reacts. I also created the link on git hub and pulled up the pages on my phone to test the differences. 

In the Upcoming Events Section, when you click on the add event button, it highlights the box. You can also remove the card from the section. 


Semantic HTML:
I used <header> for the headings of each page. That includes the Name of the University and the tagline. It also contains my navigation panel. 

I used <nav> to create my outer box that holds my navigational links. It lets the users choose where they want to go on the home page as well as find the event page. 

I used <Footer> to hold my copy right information, contact information, and links to my two different pages. 

I use <aside> for my side panel. It held information for the events details. 

I used <article> to hold major pieces of information that should be grouped together in a singular box.
